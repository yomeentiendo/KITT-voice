Cómo usarlo en el móvil

Para el micrófono, abre la página mediante HTTPS (por ejemplo, GitHub Pages) o localhost y concede permiso. Un archivo local o la vista previa de un chat pueden impedir el acceso.

«Audio de aplicación» utiliza la captura de pantalla del navegador. Elige una pestaña o fuente con audio y activa «Compartir audio». Muchos navegadores Android no ofrecen esta función: el HTML no puede saltarse esa limitación. Puedes usar el micrófono con el altavoz del teléfono o abrir un archivo de audio aquí.

No se graba ni se envía sonido. El micrófono no se reproduce por los altavoces. Demo es una animación simulada. Las luces con texto son decorativas. Pulsa sobre el panel para mostrar u ocultar los controles.
